- [x] 6.2 Verificar con procesos JAR independientes los fallos agrupados de conexión inaccesible, autenticación runtime/migrador rechazada, configuración incompleta, checksum y ejecución de migración. **Finalización:** en cada caso Java termina espontáneamente con código no cero y diagnóstico seguro antes de 75 s, sin disponibilidad ni fallback sin BD; si el comprobador debe matar el proceso el escenario falla. - [x] 6.3 Comprobar transversalmente secretos, privilegios e integridad de artefactos con los casos positivos/negativos ya creados. **Finalización:** revisión de salidas Java, bootstrap y servidor, archivos entregables y contenido del JAR no encuentra secretos sintéticos reconocibles, SQL de asignación de contraseñas ni credenciales en URL/argumentos; roles runtime/migrador conservan separación y el administrador no aparece en Java.
